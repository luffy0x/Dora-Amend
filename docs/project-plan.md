# Dora Amend 快节奏参赛规划

## 1. 目标与时间边界

- **比赛提交截止：** 2026 年 10 月 20 日。
- **首版目标：** 2026 年 9 月 6 日前完成一条可演示的高保真可信纠错闭环。
- **参赛目标：** 用可记忆的交互创新、真实验证证据和完整呈现争取任意奖项，并沉淀为 Agent UX / 前端作品集项目。
- **投入假设：** 每周约 12 小时；若低于 6 小时，保留研究、交互和验证，演示载体降级为 Figma，不扩展功能。

## 2. 制胜策略

只打磨一条黄金路径：

```text
经营问题
  → Dora 生成结论
  → 用户快速查看可信摘要
  → 对可疑结论按需追溯
  → 就地修正分析口径
  → 确认受影响范围
  → 局部重跑
  → 对比新旧结论
```

项目的记忆点不是“把日志画成流程图”，而是：

> 把 Agent 的答案从一段文字，变成可核验、可修订、可对比的结论对象。

## 5. 产品与技术范围

### 产品范围

- 一个经营分析场景：华东区 7 月利润下降归因。
- 一个桌面工作台。
- 七种连续状态：回答、可信摘要、证据追溯、纠错、影响确认、重跑、版本对比。
- 四类异常：数据过期、来源不可用、权限不足、修正存在歧义。

### 技术范围

- React + TypeScript + Vite。
- Tailwind CSS 负责样式系统。
- Lucide React 提供基础图标。
- 原生 SVG 绘制必要的数据图表。
- 本地 Mock 数据与显式有限状态模拟 Agent 行为。
- 不依赖真实模型、数据库、登录、API Key 或第三方服务。

### 明确排除

- Dora 全产品改版。
- 真实 Text-to-SQL、RAG 或 LangGraph 后端。
- 通用 Agent 行动链大图。
- 多行业、多角色和多业务案例。
- 无法解释的可信度百分比。
- 以炫技动画替代信息设计。

## 6. 设计结构

```text
Mock 场景数据
      ↓
回答与结论卡片 ←→ 可信摘要
      ↓ 点击结论
证据侧栏
      ↓ 提出修正
纠错面板
      ↓ 确认影响
局部重跑状态
      ↓ 完成
版本对比
```

数据只沿单向状态推进，不模拟真实并发，不产生外部写入；任何阶段都能退回上一稳定演示状态。

## 7. 验证计划

### 早期探索

- 3 名有数据看板、报表或 AI 分析使用经验的参与者。
- 了解他们如何判断分析是否可信、在哪里寻找依据、如何处理错误口径。
- 不展示解决方案，不使用诱导性问题。

### 方案测试

- 5 名参与者完成相同任务。
- 将“分散日志式基线”与 Dora Amend 进行方向性对比。
- 记录寻找数据范围耗时、事实/推断识别率、纠错完成率和差异解释正确率。
- 小样本结果仅作为可用性证据，不声明统计显著性。

### 目标指标

- 80% 参与者在 10 秒内找到数据截至时间和分析范围。
- 80% 参与者正确区分事实与 Agent 推断。
- 80% 参与者无提示完成一次口径纠正。
- 80% 参与者正确解释结论变化原因。

## 8. 决策门槛

1. **8 月 29 日：产品现状门槛。** 若官方产品已经存在完整的结论级追溯、就地纠错、影响预览和版本对比闭环，立即收缩或调整创新点。
2. **9 月 1 日：理解门槛。** 若早期测试者仍把证据侧栏当作开发日志，重做信息层级，不进入高保真。
3. **9 月 6 日：范围门槛。** 黄金路径未稳定前，不加入第二业务场景或真实后端。
4. **9 月 13 日：验证门槛。** 若用户不能独立纠错，优先简化交互，不用教学文案掩盖流程问题。

## 9. 风险与降级

- **体验账号能力受限：** 当前已登录，但如果无法完成示例分析或查看追溯详情，则基于官网、赛题和已核验界面完成概念方案，并在材料中明确证据边界；同步向赛事助手请求完整演示或说明。
- **实现时间不足：** 保留高保真 Figma 和核心交互视频，取消非关键异常状态。
- **视觉完成度不足：** 保持单一工作台和有限组件，先完成层级、对齐、状态反馈与可读性。
- **访谈对象不完全匹配：** 明确标注代理用户，不冒充企业经营负责人。
- **创新性被竞品覆盖：** 将重点压到“修正影响预览 + 局部重跑 + 新旧结论差异”，而不是引用和追溯本身。

### 8 月 28 日检查点

- 已完成公开资料、登录产品信息架构和一次异常回答实测。
- 已验证执行日志信息密集、可靠性结论出现较晚、异常后缺少就地修正闭环这一机会。
- 尚未核验成功生成业务结论时的来源、SQL、引用和纠错体验，产品现状门槛暂为“部分通过”。
